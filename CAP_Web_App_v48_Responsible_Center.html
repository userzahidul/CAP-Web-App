Step 3 CAP GIVEN

এখানে প্রথমে একটি সারি থাকবে। Step 2 থেকে আলাদা করে Defect Name নির্বাচন করুন; অতিরিক্ত সারির জন্য ＋ Add Row চাপুন। Step 2-এর তুলনায় কম Defect নির্বাচন করতে পারবেন। প্রতিটি সারিতে Who responsible দিতে হবে। রিপোর্টে শুধু Step 3-তে নির্বাচিত Defect-গুলো যাবে। প্রতিটি Defect-এর Finding Photo (আগের ছবি) ও Present Photo (পরের ছবি) আপলোড করুন। কোনো Recommended ফিল্ড নেই।

Backup / Restore

Backup: Backup Export (JSON) চাপুন। ডাউনলোড হওয়া CAP_Backup_তারিখ.json ফাইলটি USB/অন্য নিরাপদ ফোল্ডারে কপি করে রাখুন। এতে Master Database, CAP records, Re-check তথ্য, Manual Comments এবং আপলোড করা ছবি থাকে। নিয়মিত, বিশেষ করে অনেকগুলো রেকর্ড Submit করার পর Backup নিন।

Restore: একই অ্যাপের Restore / Import JSON বাটনে ক্লিক করে আগে নেওয়া JSON ফাইলটি নির্বাচন করুন। নিশ্চিতকরণে OK দিন। Backup-এর ডাটা বর্তমান ডাটাকে প্রতিস্থাপন করবে, তাই Restore করার আগে বর্তমান ডাটারও Backup নিন। অন্য কম্পিউটারে কাজ চালাতে HTML ফাইলের পাশাপাশি JSON Backup কপি করে Import করতে হবে। CSV-তে ছবি থাকে না; পূর্ণ Backup-এর জন্য JSON ব্যবহার করুন।

Master Database Excel থেকে পুনরায় লোড

শুধু প্রাথমিক Master Database পুনরায় যোগ হবে; বর্তমান CAP records মুছে যাবে না।
